# 由 matugen 渲染（第二趟：matugen -b wal color hex <源色>），供 mucai-regen.ps1 使用。
# 不要手工编辑 —— 每次生成都会覆盖。
#
# 为什么必须单独跑第二趟：matugen 的 base16（wal 后端）在 image 模式下会去用图片自身的
# 取色集，实测会产出近黑的垃圾值（base08 = #000004）。必须先用第一趟导出被选中的
# source_color，再用 `color hex <源色>` 生成 base16，颜色才正常。
#
# 关于亮色槽：WT 那边 intenseTextStyle=bold（粗体只换字形不换亮色），SGR 90-97 极少触发，
# 所以亮色槽直接沿用常规色，不做不可控的明度运算。
